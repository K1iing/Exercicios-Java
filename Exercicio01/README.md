# Comparador de Soma

## Descrição
Este é um programa em **Java** que lê três valores do usuário (`A`, `B` e `C`), calcula a soma de `A` e `B` e compara com `C`.  
O programa informa se a soma é menor ou maior que o valor de `C`.  

Objetivo: praticar conceitos básicos de Java, incluindo entrada de dados, estruturas condicionais e saída formatada.

---

## Funcionalidades
- Recebe três números do usuário (`A`, `B` e `C`)  
- Calcula a soma de `A` e `B`  
- Compara a soma com `C`  
- Exibe uma mensagem indicando se a soma é menor ou maior que `C`  
- Formata a saída com duas casas decimais  

---

## Tecnologias
- Linguagem: **Java**  
- Entrada de dados: `Scanner`  
- Saída formatada: `System.out.printf`
